# DeepResearch RewardBench: Evaluating Reward Models for Deep Research Report

Official repository for **DeepResearch RewardBench**, accepted to **Findings of EMNLP**.

DeepResearch RewardBench is a benchmark for evaluating reward models on long-form deep research reports. It covers preference data in pairwise, triplet, and quadruplet formats and evaluates how well reward models and LLM judges rank complex research outputs.
